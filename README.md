# Spacegrey Website

The official website for Spacegrey — a technology company delivering software, AI, and digital transformation solutions.

## Tech Stack

- [TanStack Start](https://tanstack.com/start) — full-stack React framework
- [TypeScript](https://www.typescriptlang.org/)
- [React 19](https://react.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Radix UI](https://www.radix-ui.com/) — accessible component primitives
- [Lucide React](https://lucide.dev/) — icons

## Getting Started

You need [Node.js](https://nodejs.org/) (or [Bun](https://bun.sh/)) installed.

```sh
git clone https://github.com/spacegreyyy/spacegrey_website.git
cd spacegrey_website
npm install
npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start the development server |
| `npm run build` | Build for production |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |
| `npm run format` | Format code with Prettier |

## Project Structure

```
src/
  components/   # Reusable UI components
  routes/       # File-based routing (TanStack Router)
  lib/          # Utility functions
```
